# ReNamer Pro — rename rules with a preview queue

ReNamer Pro keeps one named board on the desk: the live queue, the preview in front of you, and a short note the next operator can read. Extra queues wait for their own title.

## Session Card

| Slice | What you do in ReNamer Pro | What remains |
|-------|------------------------|--------------|
| Arrival | Open ReNamer Pro and name today's batch desk | A titled file queue |
| Focus | Keep only live steps on the ReNamer Pro board | A short preview |
| Check | Read ReNamer Pro preview before a large rename | A confirmed batch desk |

## How ReNamer Pro Sits

ReNamer Pro does not replace a silent rename, the unlabeled queue dump, or rules on files you do not own. It sits beside them as a named batch desk for one job: which rename rules are live, which file queue still matches the preview, and what the next operator should read on files you own.

## Traffic Light

| Signal | On the ReNamer Pro board | What you do |
|--------|----------------------|-------------|
| Green | Named file queue, short live preview | Continue the same rename rules |
| Amber | Two queues mixed on one preview | Split the rules before a large change |
| Red | No title, no note, a silent rename | Stop and name the batch desk first |
| Clear | Handoff written, live queues few | Close ReNamer Pro and leave the batch desk |

## Open Order

1. Open the last ReNamer Pro batch desk, not a new empty file queue.
2. Read the preview and the last handoff.
3. Finish one visible rename-rule pass inside ReNamer Pro on files you own.
4. Write what changed, then close with fewer silent renames than you found.

## Desk Fit

| Home | Personal files you own, out of the work rename |

## After a Week

A week in ReNamer Pro is not a larger silent rename. It is the same title, a shorter live queue, and a note that still makes sense before the next preview. Take finished rules off the live set so the next visit starts on the batch desk that is still open.

## Sign-off

- [ ] The ReNamer Pro workspace name is short enough to scan
- [ ] Only files you own sit on the file queue
- [ ] A second operator can read the preview handoff

## Field Note

ReNamer Pro is easier to trust when the batch desk stays smaller than the unlabeled queue dump it came from. Name the file queue, keep the live preview, finish one visible rename-rule pass, and write what changed.
